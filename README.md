# BULLBURRY — Built Bold

> Premium streetwear label with heritage-tailoring discipline.

## Brand Identity
- **Name:** BULLBURRY (power, momentum, deep crimson-plum palette)
- **Tagline:** Built Bold.
- **Palette:** Obsidian (#0B0B0C), Charcoal, Bone, and Bull Berry (deep crimson-plum).

## Tech Stack
- Vanilla HTML5
- Vanilla CSS3 (Custom design tokens, fluid clamp typography, dark/light themes)
- Vanilla JavaScript (ES6+ modular state, localStorage persistence)

## Pages
- `index.html`: Hero, cinematic SVG loader, countdown, marquee, lookbook teaser, new arrivals.
- `shop.html`: Category filtering, sort by price, color filter, animated grid.
- `product.html`: Dynamic detail view (`?id=bb-001`), gallery zoom, swatches, size guide, accordions.
- `lookbook.html`: Editorial lookbook on film.
- `about.html`: Brand manifesto and atelier standards.
- `cart.html`: Bag summary, quantity adjustments, mock express checkout with order confirmation.
- `404.html`: "Bull in a china shop" custom error page.

## Running Locally
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
